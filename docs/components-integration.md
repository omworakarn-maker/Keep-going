# การประยุกต์ UI Components ใน Keep Going

นำ React Native Paper จากหน้าตัวอย่างมาใช้ในหน้าตั้งค่า โดยสร้าง MySpaceTools เป็นองค์ประกอบที่ใช้ข้อมูลจาก AppContext ของบัญชีปัจจุบัน และวาง PaperProvider ที่ระดับรากเพื่อรองรับธีมและ Portal

| Component | การใช้งานจริง | การเชื่อมข้อมูลและเหตุการณ์ |
| --- | --- | --- |
| IconButton และ Tooltip | ปุ่มเมนูทางลัดพร้อมคำอธิบาย | เปิด Menu ด้วย state |
| Menu | เลือกเขียนบันทึกหรือดูการเติบโต | เปิด Journal และ Progress ด้วย Expo Router |
| List และ Divider | แสดงจำนวนเหตุผลที่เลือกตัวเองและแบ่งเนื้อหา | อ่าน selfReasons จาก AppContext |
| DataTable | สรุปจำนวนเช็กอิน ไดอารี และข้อความที่ไม่ได้ส่ง | อ่าน entries, diaryEntries, urgeEntries และแตะแถวเพื่อเปิด History |
| Drawer | ทางลัดวันนี้ ประวัติ และการเติบโต | เปิดหน้าจริง ไม่ใช่เปลี่ยนสถานะตัวอย่าง |
| Button | เปิดอ่านเหตุผลที่เลือกตัวเอง | เปลี่ยน state ให้ Dialog แสดง |
| Portal และ Dialog | แสดงเหตุผลที่ผู้ใช้บันทึกเองเหนือหน้าจอ | อ่าน selfReasons และรองรับกรณีไม่มีข้อมูล |
| Switch | เปิดสรุปก่อนวันอาทิตย์และการแจ้งเตือน | เรียก setter และบริการแจ้งเตือนเดิมของแอป |

ข้อมูลตัวเลขเป็นจำนวนรายการที่ AppContext โหลดอยู่ในบัญชีปัจจุบัน จึงอาจแสดงสำเนาในอุปกรณ์ระหว่างซิงก์ ไม่ใช่สถิติเรียลไทม์จากเซิร์ฟเวอร์โดยตรง การทำงานของ Drawer ในส่วนนี้เป็นรายการทางลัดภายในหน้า ไม่ใช่เมนูเลื่อนจากขอบจอ

## แนวทางตรวจรับบนอุปกรณ์

1. เปิดตั้งค่าและเทียบตัวเลขกับรายการในประวัติ
2. เพิ่มบันทึก แล้วกลับมาตรวจจำนวนและแตะแถวเพื่อเปิดประวัติ
3. เปิด Menu และ Drawer แล้วตรวจหน้าปลายทาง
4. เพิ่มเหตุผลที่เลือกตัวเองแล้วเปิด Dialog ตรวจข้อความและปุ่มปิด
5. ทดสอบเปิดปิด Switch และเปิดแอปใหม่เพื่อตรวจค่าที่บันทึก
6. ทดสอบข้อความยาว ตัวอักษรขนาดใหญ่ และการเลื่อน Dialog บนโทรศัพท์จริง

ผลตรวจโค้ดและผลใช้งานบนอุปกรณ์ควรบันทึกแยกกัน ยังไม่ถือว่ารายการตรวจรับข้างต้นผ่านจนกว่าจะได้ทดสอบจริง
