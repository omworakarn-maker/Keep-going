# Keep Going 🌱

แอปบันทึกและดูแลใจสำหรับวันที่กำลังพยายามมูฟออน ช่วยติดตามช่วงเวลา No Contact เช็กอินอารมณ์ เขียนสิ่งที่อยากบอกแต่ไม่ได้ส่ง และค่อย ๆ มองเห็นการเติบโตของตัวเองในแต่ละวัน

## ฟีเจอร์หลัก

- แบบสอบถามเริ่มต้นที่ปรับข้อความปลอบใจตามคำตอบของผู้ใช้
- ตัวนับจำนวนวัน No Contact
- เช็กอินอารมณ์ประจำวัน
- ไดอารีพร้อมวันที่และประวัติย้อนหลัง
- ข้อความที่ไม่ได้ส่ง พร้อมบันทึกเสียงได้สูงสุด 1 นาที
- กราฟอารมณ์รายสัปดาห์และรายเดือน
- สรุปเรื่องราวประจำสัปดาห์ พร้อมแชร์ออกไปได้
- Gentle streak สำหรับติดตามวันที่กลับมาดูแลใจอย่างต่อเนื่อง
- บันทึกเหตุผลที่เลือกตัวเอง เพื่อเปิดอ่านในวันที่ใจสั่นไหว
- Native tabs และ Liquid Glass บน iOS 26 (iOS รุ่นก่อนใช้หน้าตาแบบมาตรฐาน)

## ความเป็นส่วนตัว

ข้อมูลบันทึกของผู้ใช้ถูกเก็บไว้ภายในอุปกรณ์ด้วย AsyncStorage และยังไม่มีการส่งข้อมูลขึ้นเซิร์ฟเวอร์

## เทคโนโลยี

- Expo SDK 54
- React Native + TypeScript
- Expo Router
- AsyncStorage
- Expo Audio และ Expo Haptics

## เริ่มต้นใช้งาน

ต้องติดตั้ง Node.js และแอป Expo Go ก่อน จากนั้นรันคำสั่งต่อไปนี้

```bash
npm install
npx expo start
```

สแกน QR code ด้วย Expo Go เพื่อเปิดแอปบนโทรศัพท์ที่อยู่ในเครือข่ายเดียวกัน

หากต้องการเปิดจากอินเทอร์เน็ตคนละเครือข่าย ใช้ Tunnel

```bash
npx expo start --tunnel --clear
```

คำสั่งอื่นที่ใช้ได้

```bash
npm run ios
npm run android
npm run web
```

## โครงสร้างโปรเจกต์

```text
src/
├── app/          # เส้นทางและหน้าหลักของ Expo Router
├── components/   # UI ที่นำกลับมาใช้ซ้ำ
├── context/      # สถานะและข้อมูลส่วนกลางของแอป
├── screens/      # หน้าจอและขั้นตอนการใช้งาน
└── services/     # การจัดเก็บข้อมูลและบริการของแอป
```

ดูรายการฟีเจอร์ที่วางแผนและสถานะล่าสุดได้ใน [ROADMAP.md](./ROADMAP.md)

## หมายเหตุเกี่ยวกับ iPad

โปรเจกต์ตั้งค่า `supportsTablet` เป็น `false` เพื่อให้แอปทำงานในรูปแบบที่ออกแบบสำหรับ iPhone
