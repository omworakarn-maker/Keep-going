# Keep Going 🌱

> พื้นที่ส่วนตัวสำหรับค่อย ๆ รับฟังหัวใจ ในวันที่กำลังพยายามมูฟออน

Keep Going คือแอป journal และ mood tracker ที่ออกแบบมาสำหรับคนที่กำลังอยู่ในช่วง **No Contact** หรือกำลังพยายามกลับมาดูแลตัวเองหลังความสัมพันธ์จบลง แอปไม่ได้เร่งให้ผู้ใช้ต้องลืมใครภายในเวลาที่กำหนด แต่ช่วยบันทึกว่าวันนี้รู้สึกอย่างไร ผ่านอะไรมาได้บ้าง และกำลังเติบโตขึ้นอย่างไรทีละวัน

ประสบการณ์ในแอปใช้ภาษาที่อ่อนโยน ไม่ตัดสิน และไม่ทำให้ streak หรือจำนวนวันกลายเป็นแรงกดดัน ข้อมูลส่วนตัวทั้งหมดในเวอร์ชันปัจจุบันถูกเก็บไว้ภายในอุปกรณ์ของผู้ใช้

## แนวคิดของโปรเจกต์

ช่วงมูฟออนไม่ได้ดีขึ้นเป็นเส้นตรง บางวันผู้ใช้อาจเข้มแข็ง บางวันอาจยังคิดถึงหรืออยากกลับไปติดต่อ Keep Going จึงถูกออกแบบให้เป็นพื้นที่ที่ผู้ใช้สามารถ:

- ยอมรับความรู้สึกของวันนี้โดยไม่ต้องฝืนว่าตัวเองโอเค
- เห็นระยะเวลาที่เลือกดูแลตัวเองผ่านตัวนับ No Contact
- ระบายสิ่งที่อยากพูดโดยไม่ต้องส่งไปหาอีกฝ่ายจริง ๆ
- กลับมาอ่านเหตุผลที่เคยเลือกตัวเองในวันที่ใจสั่นไหว
- มองเห็นแนวโน้มอารมณ์และความก้าวหน้า โดยไม่ถูกตำหนิเมื่อเว้นช่วงใช้งาน

Keep Going เป็นโปรเจกต์เพื่อการดูแลใจและบันทึกตัวเอง ไม่ใช่เครื่องมือวินิจฉัยหรือทดแทนคำแนะนำจากผู้เชี่ยวชาญด้านสุขภาพจิต

## เส้นทางการใช้งาน

### 1. ทำความรู้จักผู้ใช้

ครั้งแรกที่เปิดแอป ผู้ใช้จะตอบคำถามทีละหน้า เช่น ไม่ได้ติดต่อกันมานานแค่ไหน รู้สึกอย่างไร และต้องการเดินหน้าต่อในรูปแบบใด คำถามถัดไปและข้อความปลอบใจจะเปลี่ยนตามคำตอบที่เลือก โดยแอปจะไม่เลือกคำตอบล่วงหน้าแทนผู้ใช้

เมื่อจบ onboarding ผู้ใช้จะได้รับข้อความสำหรับใจแบบเต็มหน้าจอก่อนเข้าสู่หน้าหลัก และวันเริ่มต้น No Contact จะถูกนำไปใช้คำนวณความก้าวหน้า

### 2. ดูแลใจในแต่ละวัน

ผู้ใช้เช็กอินอารมณ์ได้วันละครั้ง พร้อมเขียนข้อความสั้น ๆ ถึงตัวเอง หากเช็กอินแล้ว แอปจะแจ้งอย่างอ่อนโยนว่าวันนี้ได้ตอบไปแล้วแทนการสร้างข้อมูลซ้ำ

### 3. ระบายโดยไม่ต้องส่ง

เมื่อรู้สึกอยากติดต่ออีกฝ่าย ผู้ใช้สามารถเข้าสู่ flow ช่วยใจ ฝึกหายใจ เขียนข้อความที่ไม่ได้ส่ง หรือบันทึกเสียงได้สูงสุด 1 นาที ข้อความและเสียงที่เลือกเก็บจะกลับมาเปิดดูได้ในหน้าประวัติ

### 4. กลับมามองการเติบโต

อารมณ์และกิจกรรมที่บันทึกไว้จะถูกสรุปเป็นกราฟรายสัปดาห์และรายเดือน พร้อมบทสรุปที่เขียนในลักษณะจดหมายถึงผู้ใช้ บทสรุปประจำสัปดาห์จะพร้อมในวันอาทิตย์ หรือผู้ใช้สามารถเลือกเปิดดูก่อนได้จากการตั้งค่า

## ภายในแต่ละแท็บ

### วันนี้

- แสดงจำนวนวันที่อยู่ในช่วง No Contact
- เช็กอินอารมณ์ประจำวันและเขียนข้อความสั้น ๆ
- แสดงข้อความให้กำลังใจประจำวัน
- แสดงเหตุผลที่ผู้ใช้เคยบันทึกไว้ว่าเหตุใดจึงเลือกตัวเอง
- ทางลัดเข้าสู่ flow เมื่อตอนนี้รู้สึกอยากทักหาเขา

### เขียนบันทึก

- เขียนไดอารีในหน้าตาที่ได้แรงบันดาลใจจากกระดาษจริง
- ใส่หัวข้อ เนื้อหา วันที่ และความรู้สึกของบันทึก
- ไม่มีการเลือกอารมณ์เริ่มต้นให้โดยอัตโนมัติ
- แสดงข้อความให้กำลังใจหลังบันทึกเสร็จ

### ย้อนหลัง

- อ่านเช็กอินและไดอารีย้อนหลังตามวันที่
- เปิดอ่านข้อความที่ไม่ได้ส่งในรูปแบบฟองแชทด้านขวา
- เล่นไฟล์เสียงที่เคยบันทึกไว้
- กดค้างเพื่อลบรายการที่ไม่ต้องการเก็บ

### การเติบโต

- ปฏิทินวันที่กลับมาเช็กอิน
- กราฟอารมณ์รายสัปดาห์และรายเดือน
- สรุปอารมณ์ที่เกิดบ่อยและกิจกรรมที่ทำในสัปดาห์นั้น
- Gentle streak ที่ให้กำลังใจโดยไม่ตำหนิเมื่อผู้ใช้ขาดวัน
- แชร์บทสรุปได้โดยไม่แนบบันทึกส่วนตัวไปด้วย

### ตั้งค่า

- เปลี่ยนวันเริ่ม No Contact
- เลือกว่าจะเปิดบทสรุปก่อนวันอาทิตย์หรือรอให้ครบสัปดาห์
- เพิ่ม แก้ไข และลบเหตุผลที่เลือกตัวเอง
- ล้างข้อมูลและเริ่มทำแบบสอบถามใหม่
- อธิบายว่าข้อมูลยังถูกเก็บอยู่ภายในอุปกรณ์

## การออกแบบ

- **Minimal:** ใช้องค์ประกอบเท่าที่จำเป็น สีอ่อน และพื้นที่ว่างเพื่อให้หน้าจอรู้สึกสงบ
- **Gentle by design:** ข้อความไม่ตัดสิน ไม่เร่ง และไม่ใช้ความต่อเนื่องเป็นแรงกดดัน
- **Safe area first:** แถบหัวและเนื้อหาคำนึงถึงพื้นที่กล้องและแถบสถานะบน iPhone
- **Native navigation:** ใช้ Native Tabs ของ Expo Router โดยแสดง Liquid Glass บน iOS 26 และใช้รูปแบบ native ปกติบน iOS รุ่นก่อน
- **Focused motion:** หน้าหลักสลับทันทีโดยไม่ fade ส่วน animation ถูกเก็บไว้เฉพาะ flow ที่ช่วยเล่าเรื่อง เช่น onboarding และหน้าปลอบใจ
- **Phone-first:** อินเทอร์เฟซออกแบบสำหรับโทรศัพท์ และปิดการรองรับ layout แบบเต็มขนาด iPad ในการตั้งค่า iOS

## ความเป็นส่วนตัวและการจัดเก็บข้อมูล

เวอร์ชันปัจจุบันไม่มีบัญชีผู้ใช้ ฐานข้อมูลออนไลน์ หรือระบบ sync ข้ามอุปกรณ์

- ข้อมูล onboarding, เช็กอิน, ไดอารี, การตั้งค่า และเหตุผลที่เลือกตัวเองถูกเก็บด้วย AsyncStorage
- ไฟล์เสียงจากข้อความที่ไม่ได้ส่งถูกคัดลอกไปเก็บใน document directory ของแอป
- เมื่อลบรายการเสียง แอปจะลบทั้งข้อมูลรายการและไฟล์เสียงที่เกี่ยวข้อง
- ไม่มีการอัปโหลดเนื้อหาส่วนตัวขึ้นเซิร์ฟเวอร์
- การลบแอปหรือล้างข้อมูลอาจทำให้บันทึกภายในเครื่องสูญหาย เพราะยังไม่มีระบบสำรองข้อมูล

ฟีเจอร์ล็อกแอปด้วย Face ID/Touch ID และการซ่อนข้อมูลใน App Switcher ยังอยู่ในแผนพัฒนา จึงไม่ควรถือว่าเวอร์ชันนี้มีระบบป้องกันดังกล่าวแล้ว

## เริ่มต้นพัฒนา

### สิ่งที่ต้องมี

- Node.js และ npm
- Expo Go บนโทรศัพท์ หรือ iOS Simulator/Android Emulator
- Xcode หากต้องการใช้ iOS Simulator บน macOS

### ติดตั้งและรัน

```bash
git clone https://github.com/omworakarn-maker/Keep-going.git
cd Keep-going
npm install
npx expo start
```

หลัง Metro Bundler เริ่มทำงาน สามารถสแกน QR code ด้วย Expo Go ได้ หากโทรศัพท์และคอมพิวเตอร์อยู่ในเครือข่ายเดียวกัน

### เปิดผ่านอินเทอร์เน็ตคนละเครือข่าย

```bash
npx expo start --tunnel --clear
```

Tunnel ต้องเชื่อมต่ออินเทอร์เน็ตตลอดเวลาที่กำลังทดสอบ และเครื่องที่รัน Metro ต้องเปิดอยู่ นี่เป็นวิธีแชร์ development build ชั่วคราว ไม่ใช่การ deploy แอปสำหรับใช้งานจริง

### คำสั่งที่ใช้บ่อย

```bash
npm run ios       # เปิดใน iOS Simulator
npm run android   # เปิดใน Android Emulator
npm run web       # เปิดเวอร์ชันเว็บสำหรับทดสอบ
npx tsc --noEmit  # ตรวจ TypeScript
```

การมีคำสั่ง `web` หมายถึงโปรเจกต์รองรับการทดลองรันผ่าน Expo Web แต่ยังไม่ได้หมายความว่ามีเว็บไซต์ production ที่ deploy แล้ว

## โครงสร้างโปรเจกต์

```text
src/
├── app/          # File-based routes, root stack และ native tab layout
├── components/   # UI ส่วนกลาง เช่น Screen, header และปุ่ม
├── constants/    # สี ธีม รายการอารมณ์ และข้อความของแอป
├── context/      # App state และ action ที่ทุกหน้าใช้งานร่วมกัน
├── navigation/   # Navigation เดิมสำหรับ compatibility
├── screens/      # หน้าจอและ interaction หลักของแต่ละฟีเจอร์
├── services/     # การอ่าน เขียน และล้างข้อมูลภายในเครื่อง
├── types/        # TypeScript types ของข้อมูลและ navigation
└── utils/        # ฟังก์ชันวันที่และ utility ที่ใช้ร่วมกัน
```

จุดเริ่มต้นของแอปคือ `expo-router/entry` โดย `src/app/_layout.tsx` ดูแล provider และเส้นทางระดับบน ส่วน `src/app/(tabs)/_layout.tsx` ดูแล navigation หลักทั้งห้าแท็บ

## สถานะปัจจุบัน

โปรเจกต์ยังอยู่ระหว่างการพัฒนาและทดสอบผ่าน Expo Go ฟีเจอร์หลักสำหรับ onboarding, daily check-in, diary, unsent messages และ progress ใช้งานได้แล้ว ส่วนงานก่อนปล่อยให้ผู้ใช้ทั่วไป เช่น App Icon, Splash Screen, Dark Mode, Privacy Policy, biometric lock และการทดสอบบนอุปกรณ์หลายขนาด ยังอยู่ในแผน

ดูรายการที่ทำเสร็จและแผนลำดับถัดไปได้ใน [ROADMAP.md](./ROADMAP.md)
